# DCA 백테스트 API

`POST /api/backtests`는 저장된 DCA 전략과 과거 가격 바를 사용해 가상 매수 결과를 계산합니다.
백테스트 중에는 거래소·증권사 API를 호출하지 않으며, 주문 이력이나 실제 보유 자산도 변경하지
않습니다.

## 호출 전제

- `strategy_id`는 저장된 DCA 전략을 가리켜야 한다. 현재 DCA 매수만 지원한다.
- `initial_cash`는 0보다 커야 하며, 한 번의 백테스트에서 전략 주문과 같은 통화로 해석한다.
- `bars`는 하나 이상, 최대 20,000개를 입력한다. `timestamp`는 ISO 8601 형식이고 중복될 수 없다.
- 입력된 가격 바는 시간순으로 정렬해 처리한다. 타임존이 없는 `timestamp`는 KST로 해석한다.
- 인증을 활성화한 경우 이 `POST` API는 `operator` 권한이 필요하다.

## 요청

```json
{
  "strategy_id": 1,
  "initial_cash": 1000000,
  "bars": [
    {
      "timestamp": "2026-08-03T09:00:00+09:00",
      "prices": {"005930": 70000}
    },
    {
      "timestamp": "2026-08-03T10:05:00+09:00",
      "prices": {"005930": 70500}
    }
  ]
}
```

`prices` 대신 단일 종목의 `symbol`과 `price`를 사용할 수도 있습니다.

```json
{
  "timestamp": "2026-08-03T10:05:00+09:00",
  "symbol": "KRW-BTC",
  "price": 150000000
}
```

전략에 설정된 실행일·실행 시각 이후 해당 날짜의 첫 번째 가격 바에서 주문을 체결합니다.
실행 일정 판정은 KST 기준이며, 가격 바 timestamp에 타임존이 없으면 KST로 해석합니다.

## 응답

응답에는 다음 결과가 포함됩니다.

- `trades`: 체결 또는 거부된 가상 주문과 적용 비용
- `holdings`: 종료 시점의 가상 보유 수량, 평가금액, 손익
- `equity_curve`: 가격 바별 현금·보유금액·총 평가금액
- `fees`, `taxes`, `slippage`: 누적 거래 비용
- `trade_count`, `rejected_count`, `pnl`, `return_pct`: 요약 지표

각 `trades` 항목의 `status`는 `filled` 또는 `rejected`이며, 거부된 주문에는 사유가 포함된다.
`equity_curve`는 각 가격 바 처리 후의 현금·보유금액·총 평가금액을 기록한다.

수수료·세금은 전략의 직접 설정값과 `config/fee-policies.json`을 사용합니다. 슬리피지는 매수
체결 가격과 예상 비용에 반영됩니다. 업비트 실시간 요율 조회나 기타 외부 사전검증은 실행하지
않습니다.

## 현재 제한사항

- DCA 매수 전략만 지원하며, 매도·익절·손절 신호는 아직 시뮬레이션하지 않습니다.
- 한 번의 백테스트에서는 하나의 통화만 사용할 수 있습니다.
- 가격 데이터가 없는 종목은 해당 예정 주문을 거부합니다.
- 결과는 현재 API 응답으로만 제공하며 백테스트 전용 DB 저장과 화면 UI는 아직 없습니다.
- 과거 환율 변환은 지원하지 않으므로 초기 현금과 전략 주문 통화가 일치해야 합니다.

이 결과는 가정된 가격·비용에 대한 검증 자료이며 실제 체결 가격이나 수익을 보장하지 않습니다.
